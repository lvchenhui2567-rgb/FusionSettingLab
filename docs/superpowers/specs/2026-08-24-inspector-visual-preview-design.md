# Inspector 视觉预览设计

## 目标

在现有离线 Fusion `.setting` 编辑器右侧增加一个 DaVinci Resolve Inspector 风格的“预览”标签页，让用户按最终公开属性顺序、页面和分组查看近似呈现效果。

预览必须可交互，但所有交互仅改变浏览器内的预览状态，不修改公开属性配置、解析结果、`.setting` 输出或 DRFX 内容。

## 安全边界

- 保留现有“检查”“变更”“结果”标签及其行为。
- 不改变现有 `buildInputsBody()`、局部补丁、校验、下载和 DRFX 打包逻辑。
- 预览状态保存于独立的 `previewState`，不得写入 `state.controls`。
- 页面切换、Label 展开、滑块、复选框、文本输入和按钮点击只用于演示。
- 网站按钮在预览中不打开 URL，只显示按下反馈，避免意外外部操作。
- 重新载入文件时清空预览状态；公开属性结构改变后只清理失效的预览值。
- 推断出的控件类型仅用于渲染，不能用于生成或修改 `UserControls`。
- 无法可靠推断时使用通用只读控件，并显示“近似预览”提示。
- 当前版本备份位于 `backups/index-before-inspector-preview-2026-08-24.html`。

## 页面结构

右侧标签顺序调整为：

1. 预览
2. 检查
3. 变更
4. 结果

载入文件后仍默认显示“检查”，避免改变用户现有工作流。用户主动打开“预览”后看到以下结构：

- 顶部说明条：提示这是近似预览，交互不会写回模板。
- 页面标签：按 `state.pages` 显示 `Controls`、`Text`、`Layout` 等页面。
- Inspector 主体：按 `state.controls` 原始顺序过滤当前页面并渲染。
- 空页面提示：当前页面无公开属性时显示明确说明。

桌面采用已确认的标准密度；窄屏下压缩标签名称列和数值输入宽度，但不产生水平滚动。

## 数据模型

### 控件解析元数据

每个普通公开属性在现有字段外增加只读的 `preview` 元数据：

- `controlType`：来自 `INPID_InputControl`。
- `dataType`：来自 `LINKID_DataType`。
- `integer`：来自 `INP_Integer`。
- `min`：优先读取 `INP_MinScale`，其次读取可识别的最小值字段。
- `max`：优先读取 `INP_MaxScale`，其次读取可识别的最大值字段。
- `defaultValue`：优先读取宿主 `Inputs` 当前 `Value`，其次读取 `INP_Default`。
- `isLinked`：当前值是连接、表达式或无法安全转成标量时为真。
- `approximate`：类型或取值仅能保守推断时为真。

这些字段只从原文读取，不参与序列化。

### 独立预览状态

`previewState` 包含：

- `page`：当前预览页面。
- `expandedLabels`：按稳定控件键保存 Label 展开状态。
- `values`：按稳定控件键保存用户在预览中操作后的临时值。
- `pressedButton`：网站按钮的短暂按下反馈。

稳定控件键使用现有 `controlKey(control)`；如果存在重复公开属性，则追加当前序号，仅用于本轮预览 DOM 标识。

## 控件推断

特殊元素使用已识别的 `kind` 直接渲染：

- `label`：分组标题和展开箭头，折叠范围遵循 `numInputs`。
- `separator`：横向分隔线。
- `message`：只读说明块。
- `logo`：显示内嵌图片；无有效图片时显示占位。
- `website`：DaVinci 风格按钮；点击不打开网址。

普通控件按以下优先级推断：

1. `ColorControl` 或名称/数据结构明确表示颜色：颜色条和色值摘要。
2. `CheckboxControl`、`INP_Integer = true` 且范围为 0 到 1，或布尔默认值：开关。
3. `TextEditControl`、`TextControl` 或字符串默认值：文本框。
4. 数字默认值且存在范围：滑块加数值输入。
5. 数字默认值但无范围：数值输入。
6. 连接、表达式、复合对象或未知类型：通用只读框并标注“近似”。

控件推断宁可退化，不根据显示名称强行猜测会误导用户的类型。

## 交互与数据流

1. `analyzeSetting()` 继续生成公开属性列表，并附加预览只读元数据。
2. `rebuild()` 完成现有输出生成和检查后调用 `renderPreview()`。
3. `renderPreview()` 根据当前页面、Label 范围和 `previewState` 生成 DOM。
4. 用户操作控件时只更新 `previewState.values`，不调用 `rebuild()`。
5. 编辑区改变名称、页面、顺序或特殊元素后，现有 `rebuild()` 重新渲染预览并保留仍有效的临时值。
6. 新文件载入时调用 `resetPreviewState()`，避免前一个文件的状态泄漏。

## 错误与退化处理

- 缺少定义或当前值时，显示 `未提供默认值`，不抛出错误。
- 非有限数字不渲染滑块，退化为只读文本。
- 最小值大于等于最大值时忽略范围，仅渲染数值输入。
- Base64 Logo 无效时显示图片占位，不影响主校验结果。
- Label 范围越界沿用现有校验；预览端额外截断到列表末尾，避免 DOM 异常。
- 重复公开属性仍按顺序全部显示，预览状态键使用序号消歧。

- 验证切换页面不改变编辑区页面字段。
- 验证编辑区改名、排序、换页后预览立即同步结构。
- 验证 390×844 窄屏无水平溢出。
- 运行现有 `.setting` 重新解析和修改边界校验。
- 重新下载 `.setting` 并打包 DRFX，确认内容与未操作预览时一致。
